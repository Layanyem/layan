# موقع ليان

موقع عربي شخصي وخفيف، مبني بـ HTML وCSS وJavaScript دون أطر عمل أو خطوات بناء. يعمل مباشرة على GitHub Pages.

## معاينة الموقع محليًا

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم يُفتح العنوان `http://localhost:8000` في المتصفح.

## أين أضع التطبيقات والصور؟

لا ترفعي التطبيق التنفيذي (مثل APK أو EXE) إلى ملفات الموقع إذا كان كبيرًا. الخيار السهل هو رفعه إلى **GitHub Releases** في المستودع، أو إلى متجر التطبيقات، ثم نسخ رابط التنزيل ووضعه في بيانات التطبيق داخل `script.js` في الخاصية `download`. إلى أن يتوفر الرابط، يظهر زر غير مفعّل بدل رابط تنزيل وهمي.

لكل تطبيق صفحة تفاصيل مشتركة بعنوان `app.html?app=معرّف-التطبيق`. يصل المستخدم إليها بالنقر على بطاقة التطبيق، ويجد فيها الوصف والميزات ولقطات الشاشة وزر التنزيل. تُدار بيانات الصفحة من العنصر نفسه داخل مصفوفة `apps` في `script.js`.

تُحفظ صور كل تطبيق في مجلده داخل `assets/apps/`:

- `assets/apps/image-toolbox/` للصور ولقطات شاشة Image Toolbox.
- `assets/apps/ai-video-studio/` للصور ولقطات شاشة AI Video Studio.

تُحفظ لقطات الشاشة داخل مجلد التطبيق، وتُحدّث مساراتها في قائمة `screenshots` الخاصة به في `script.js`. ينبغي استبدال صور SVG التجريبية بلقطات فعلية قبل النشر النهائي.

أيقونة Image Toolbox محفوظة في `assets/apps/image-toolbox/app-icon.webp`، وأيقونة AI Video Studio في `assets/apps/ai-video-studio/app-icon.webp`. تظهر أيقونة كل تطبيق داخل بطاقته وصفحة التفاصيل. لإضافة تطبيق جديد، تُحفظ أيقونته في مجلده ويُضاف مسارها ووصفها في الخاصيتين `icon` و`iconAlt`. الأيقونتان الحاليتان مضغوطتان بصيغة WebP بقياس 256 × 256 بكسل.

## تغيير صور البطاقات المؤقتة

لاستبدال الرسومات المؤقتة، تُحفظ الصور الجديدة مع الإبقاء على اسم الملف، أو يُحدّث مسار `image` في بيانات التطبيق داخل `script.js`:

- صورة بطاقة تطبيق تعديل الصور: `assets/image-toolbox.svg`
- صورة بطاقة تطبيق توليد الفيديو: `assets/ai-video-studio.svg`
- أيقونة المتصفح: `assets/favicon.ico` و`assets/favicon-32.png`
- أيقونة إضافة الموقع إلى شاشة الهاتف: `assets/apple-touch-icon.png`
- النسخة المضغوطة الكبيرة من الأيقونة: `assets/favicon-512.webp`

يُفضّل أن تكون صور بطاقات التطبيقات أفقية بنسبة تقارب 1200 × 640 بكسل. تُحفظ الصور في مجلد `assets` وتُستخدم مسارات نسبية مثل `assets/my-new-app.jpg`.

## إضافة تطبيق جديد

لإضافة تطبيق، يُضاف عنصر إلى مصفوفة `apps` في أعلى `script.js` مع تعديل القيم في المثال التالي:

```js
{
  number: "03",
  category: "فئة التطبيق",
  name: "اسم التطبيق",
  description: "وصف قصير للتطبيق.",
  details: "وصف تفصيلي يظهر في صفحة التطبيق.",
  slug: "اسم-فريد-للتطبيق",
  icon: "assets/apps/my-app/app-icon.webp",
  iconAlt: "وصف أيقونة التطبيق",
  image: "assets/my-new-app.jpg",
  imageAlt: "وصف الصورة لقارئات الشاشة",
  screenshots: [
    { image: "assets/apps/my-app/screenshot-1.jpg", alt: "وصف لقطة الشاشة الأولى" },
    { image: "assets/apps/my-app/screenshot-2.jpg", alt: "وصف لقطة الشاشة الثانية" }
  ],
  tags: ["ميزة أولى", "ميزة ثانية"],
  features: ["الميزة الأولى", "الميزة الثانية"],
  status: "متاح الآن",
  download: "https://example.com/app",
  downloadLabel: "تنزيل التطبيق"
}
```

تُحفظ ملفات اللقطات في مجلد التطبيق تحت `assets/apps/`. يجب أن تكون قيمة `slug` فريدة وأن تطابق المعرّف في الرابط. إذا لم يكن التطبيق متاحًا بعد، تُترك `download` فارغة وتُضبط `status` على `"قريبًا"`؛ ويبقى زر التنزيل غير مفعّل حتى إضافة رابط المتجر أو الملف.

## النشر على GitHub Pages

يتضمن المستودع سير عمل ينشر الموقع تلقائيًا عند كل تحديث لفرع `main`.

1. تُرفع ملفات المشروع إلى فرع `main`.
2. من إعدادات المستودع في GitHub، تُفتح **Settings → Pages**.
3. يُختار **GitHub Actions** ضمن **Build and deployment → Source**.
4. بعد نجاح سير العمل من صفحة **Actions**، سيكون الموقع على `https://layanyem.github.io/layan/`.

## الملفات الرئيسية

- `index.html`: محتوى الصفحة وأقسامها.
- `app.html`: صفحة تفاصيل مشتركة لكل تطبيق.
- `styles.css`: الألوان والتصميم المتجاوب مع الشاشات المختلفة.
- `script.js`: بيانات التطبيقات، وبطاقات المتجر وصفحات التفاصيل.
- `assets/`: الصور المؤقتة وأيقونة الموقع.
- `.github/workflows/deploy-pages.yml`: النشر التلقائي إلى GitHub Pages.
